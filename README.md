# business-cards
半導體暨電子產業線上名片集 (依產業別、公司別、職階分層歸納)

## 專案簡介
本專案為半導體暨電子產業線上名片集，旨在依據產業別、公司別與職階分層歸納 41 位真實產業聯絡人資訊 (涵蓋 7 大產業類別、24 家企業與金融機構)。

## 作業標準流程 (SOP)
1. **名片收集與驗證**：定期核對名片資訊（姓名、公司、職稱、聯絡電話、Email）。
2. **分類與歸納**：依 7 大產業類別、公司名稱及高階/中階/基層職階進行分層。
3. **資料更新與維護**：若有職務變動，需於 3 個工作天內更新本專案名片資料。
